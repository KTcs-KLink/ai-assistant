# 보류 원문 7,235개 인사 여부 재분류

기존 인사 여부 미확정 원문을 다시 분류하고, 인사 외 자료를 별도 파일·검색으로 분리했다. 한국전력 공개 참고자료를 사용했으며 Supabase 적재는 계속 보류한다. 작업 브랜치는 `feat/hr-reclassification-20261108`이다. PR은 생성하지 않는다.

| 이번 대상의 분류 | 검색 조각 수 | 처리 |
|---|---:|---|
| 인사 관련 | 608 | 인사 검토 후보로 유지 |
| 인사 외 업무 | 5,363 | 기본 인사 검토 검색에서 제외하고 별도 조회 |
| 인사·다른 업무 혼합 | 662 | 내부 인사 내용의 손실을 막기 위해 보존 |
| 판단 보류 | 602 | 구조·문맥·적용 대상·인용 근거 등의 확인 필요 |
| 합계 | 7,235 | 중복·누락 없는 분리 |

이번 대상은 178개 문서의 조문·서식 원문 단위 3,014개다. 긴 원문을 중복 없는 3,581개 구간으로 나눠 기존 `.env`에 지정된 `gpt-6-luna`로 분류를 제안받고, 코드가 ID·원문 해시·인용 위치·전체 구간 연결을 검사했다. 각 구간의 전체 본문을 검토했으며 입력 한도를 맞추기 위해 본문을 잘라 버리지 않았다. 이전 인사 표시 535개 검색 조각은 새 재분류 분모에 포함하지 않았다.

## 분류 기준과 수정

내부 직원·임원·지원자·퇴직자·가족의 채용, 근태·휴가, 보수·복리후생, 직원 교육·평정·징계 등을 인사로 다뤘다. 전력 공급·요금·계약·입찰·설비·공사 업무와 외부 업체 근로자의 자격·고용 평가는 구분했다. 인사 내용이 함께 있으면 혼합으로, 판단 근거가 부족하면 보류로 남겼다.

원문 인용·형식 검사를 반복해서 통과하지 못한 14개 구간에 걸친 검색 조각 20개는 판단 보류에 포함했다. 연결 실패만으로 원문을 읽은 것으로 처리하지 않았다. 추가 원문 대조에서 깨진 본문의 과도한 추론 1개 구간과 업체의 고용·기술자·보호장비 기준을 내부 인사 근거로 제시한 6개 구간도 보류로 수정했다. 수정 전 모델 제안과 호출·실패 기록을 보존했다.

이는 자동 분류와 일부 실패·적용 대상 사례에 대한 원문 대조 결과다. 인용 일치는 전체 의미 정확성·완전성, 독립적인 사람 승인, 현행성 또는 KTcs 적용을 보증하지 않는다.

## 로컬 파일과 검색 연결

산출물 기준 경로는 저장소 상위의 `outputs/klink_hr_reclassification_20261108/`이다.

- `README.md`: 분류 기준·집계·원문 근거 예시·실제 분리 파일 링크
- `separated/{hr,non_hr,mixed,review_required}/windows.jsonl`: 분류별 실제 원문 조각, 원본 ID·위치·해시 보존
- `window-classification.jsonl`, `unit-classification.jsonl`: 전체 분류 목록과 원문 구간 연결
- `proposals/`, `calls/`: 원문 근거를 가진 자동 제안과 검사·재시도 기록
- `source-review-overrides.jsonl`, `scope-support-audit.json`: 적용 대상 오류·추론을 보류로 수정한 근거
- `domain-review-search.sqlite3`: 새 로컬 읽기 전용 검색 파일
- `local-artifact-verification.json`, `secret-scan.json`, `browser-verification.json`: 실제 검사 기록
- `revisions/before-source-scope-audit/`: 추가 원문 대조 이전 결과 보존

서비스 검토 검색은 새 분류 7,235개와 이전 인사 표시 535개를 합친 7,770개를 수용한다. 기본 `hr_candidates`는 인사 1,143개·혼합 662개·판단 보류 602개, 합계 2,407개이며 인사 외 5,363개를 제외한다. 인사 외 자료도 `non_hr` 분류에서 별도 조회할 수 있다.

`GET /api/benefits/hr/review-evidence?q=...&category=...`의 분류 값:

| category | 범위 |
|---|---|
| `hr_candidates` | 인사·혼합·판단 보류, 기본값 |
| `hr` | 인사로 분류된 자료 |
| `non_hr` | 분리된 인사 외 자료 |
| `mixed` | 혼합 자료 |
| `needs_review` | 판단 보류 |
| `all` | 전체 검토 자료 |

분류 필터는 검색 결과 개수를 자르기 전에 적용한다. 응답은 분류와 관계없이 `review_only=true`, `answer_eligible=false`, `human_approved=false`, `used_for_generation=false`를 유지한다. 기존 답변 근거 528개 조문·536개 검색 조각은 그대로다. 원본·이전 검색 파일·문서 벡터·960 골든셋을 변경하거나 다른 프로젝트 자료를 합치지 않았다.

실행 예: `python scripts/launch_hr_domain.py --port 8846 --source-scope expanded --review-domains reclassified --no-open`. 기존 서비스가 해당 포트를 쓰면 자동으로 종료하지 않는다. 이전 분류와 비교할 때는 다른 포트에서 `--review-domains baseline`을 명시한다. 새 검색 파일과 분류 목록의 해시가 맞지 않으면 분리 검색을 제공하지 않는다.
