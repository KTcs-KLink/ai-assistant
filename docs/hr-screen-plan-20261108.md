# K:LINK 직원·관리자 화면 구성과 와이어프레임

기준일: 2026-11-08. 복지 추천을 제외한 인사 AI SaaS의 화면 설계다. [클릭형 와이어프레임](http://127.0.0.1:8825/hr/wireframes)에서 직원/관리자, PC/모바일 배치, 전체 화면 구성을 전환하고 각 구현 화면을 열 수 있다. 와이어프레임의 회색 상자·행·차트 영역은 배치 표시이며 실제 사용량·업무 실적으로 표시하지 않는다.

## 공통 배치

PC는 왼쪽 업무 메뉴, 위쪽 현재 위치·검색·계정, 가운데 핵심 업무, 필요한 경우 오른쪽 상세 패널을 사용한다. 직원 화면은 질문과 본인 문의를 중심으로, 관리자 화면은 목록·필터·실행 상태·상세 확인을 중심으로 배치한다. 좁은 화면은 메뉴를 접고 내용을 세로로 쌓는다. 큰 문서 표는 표 안에서 가로로 이동하고 페이지 전체가 옆으로 밀리지 않게 구성한다.

로딩·빈 목록·오류·조회 권한 없음·저장 중·수정 충돌을 구분한다. 확인되지 않은 회사 적용, 연결 전 기능, 추정 비용은 해당 화면 가까이에 표시한다. 데이터가 없을 때 실적이나 직원 수를 임의로 채우지 않는다.

## 직원 화면 6개

| ID | 화면·경로 | 주요 영역과 행동 | 표시 경계 |
| --- | --- | --- | --- |
| E01 | 업무 홈 `/hr` | 빠른 AI 질문, 문의 등록·규정·공식 양식 바로가기, 본인 문의, 자주 찾는 원문 | 질문은 AI 작성창으로 이동한 뒤 전송. 가상 휴가 잔액·급여·복지 카드 제외 |
| E02 | AI 업무 도우미 `/hr/assistant` | 현재 대화·질문 목록, 질문 작성, 답변과 인용, 근거 자료 패널, 직접 원문 검색 | 실제 528개 답변 조문과 3,334개 검토 전용 구간 구분. 검토 발췌는 답변 생성에 넣지 않음 |
| E03 | 규정·양식 `/hr/library` | 검색, 답변용 규정·검토용 발췌·공식 양식 탭, 문서 정보와 원문 위치 | 한전 참고자료. KTcs 적용·현행성·회사 승인 미확인. 지원 서식과 실제 회사 제출 연결 구분 |
| E04 | 내 문의 `/hr/requests` | 본인 문의 상태별 목록, 일반 문의 등록, 상세·처리 안내, 진행 중 취소 | 로컬 체험 세션에 연결. 실제 회사 신청·결재·외부 알림과 별도 |
| E05 | 내 계정 `/hr/profile` | 접속 정보, 회사 인증 연결 상태, 현재 참고자료, 데이터 보관 범위 | 읽기 전용. 가족·복지 조건 입력 제외, 회사 직원 정보·SSO 미연결 |
| E06 | 연결·적용 상태 `/hr/status` | 실제 원문·AI 연결, 양식 지원, 인증·저장·운영 승인 상태 | 기능 연결 확인을 조직 승인·KTcs 적용 확인으로 바꾸지 않음 |

직원 흐름은 **질문 작성 → 실제 답변 → 인용 원문 확인 → 필요시 문의 등록 → 처리 안내 확인**이다. 규정부터 찾으려는 사용자는 홈에서 규정·양식으로 바로 이동할 수 있다.

관리자 흐름은 **원문 확인 → 선택 문서 재수집·검사 → 검토 기록 → 별도 스테이징 → 사용량·비용 확인**이다. 기존 검색 서비스에 새 버전을 활성화하는 기능은 현재 연결하지 않았다.

## 역할별 접근

| 체험 역할 | 허용 업무 |
| --- | --- |
| 직원 | 본인의 문의 등록·조회·취소, 기존 AI·원문 화면 |
| 인사 담당자 | 직원 문의 처리, 원문 조회·검토, 연결 진단 |
| 데이터 담당자 | 원문·수집/재적재 작업·검토, 연결 진단 |
| 사용량 분석 담당자 | 토큰·비용, 변경 이력, 연결 진단 |
| 운영 책임자 | 관리자 전체 화면과 예산·단가 설정 |

권한은 서버에서도 검사한다. 현재 로컬 체험 역할이며 실제 직원·조직·SSO·테넌트별 인증과 사용자 발급·조직 권한 편집은 연결 전이다. 관리자 진입과 직원 접속은 별도 체험 세션으로 관리한다.

## 제외와 보존

복지 추천 메뉴·카드·가족 조건·추천 자동 조회를 활성 직원 흐름에서 제외했다. 기존 `/hr/benefits`는 업무 홈으로, `/hr/preparations`는 내 문의로 이동한다. 기준 시안 8824와 이전 화면 코드는 보존했다. 기존 실제 챗봇의 원문 검색·답변·인용 검증은 유지한다. Supabase 적재는 계속 보류한다.

공식 제품 벤치마킹, 실제 실행 범위와 검사 기록은 [직원·관리자 구현 기록](hr-user-admin-20261108.md)을 참고한다.
