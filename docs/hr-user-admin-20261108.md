## 직원 기능

- AI 질문 작성과 기존 챗봇으로 이어쓰기. 실제 전송은 작성창에서 사용자가 전송할 때만 수행한다.
- 규정·공식 양식 상태, 내 문의와 자주 찾는 원문으로 바로 이동한다. 가상 잔여 휴가·급여·처리 실적을 만들지 않는다.

- 일반 문의를 로컬 저장소에 등록하고 본인의 문의·상태·처리 안내만 조회한다. 진행 중 문의 취소와 관리자 처리 결과 확인을 지원한다.
- 문의는 같은 체험 세션에 연결된다. 실제 직원 ID·SSO에 연결된 영구 인사 이력이나 회사 신청·결재가 아니다. 실제 직원 정보·진단 내용·키 등의 입력을 안내하지 않으며 연락처·주민번호·키 패턴을 서버에서 차단한다.

## 기존 연결 보존

기존 8846 답변 서비스와 8841 인코더를 수정하거나 재시작하지 않는다. 현재 UI의 답변 요청만 새 로컬 게이트웨이 8848을 거친다. 게이트웨이는 기존 세션을 8846에서 확인하고 `{question}`만 전달한다. 원래 답변 JSON·인용·조건 검증은 유지한다. 나머지 기존 `/api/benefits` 요청은 8846으로 직접 연결한다.

게이트웨이는 모델의 `provider_calls[].usage`를 읽어 사용량을 기록한다. 질문·답변 본문, 프로필, 쿠키, 키와 `.env`는 사용량·감사 저장소에 넣지 않는다. 모델 호출 없이 보류된 요청은 실제 0회로, 사용량 확인에 실패한 요청은 미확인으로 구분한다. 이전 직접 호출이나 집계 시작 전 비용을 0원으로 소급 확정하지 않는다.

기본 계산 단가는 [OpenAI GPT-6 Luna 공식 문서](https://developers.openai.com/api/docs/models/gpt-6-luna)의 Standard 기준으로 100만 토큰당 일반 입력 $0.10, 캐시 입력 $0.01, 캐시 쓰기 $0.125, 출력 $0.50을 사용했다. 실제 처리 등급·지역·계약 할인 등을 확인한 청구액은 아니므로 추정 비용으로 표시한다. reasoning 토큰을 출력에 중복 합산하지 않는다. 관리자 입력 단가는 출처를 관리자 입력으로 바꾸고 호출 시점의 단가를 보존한다.

예산 차단은 완료된 요청의 누적 추정액 기준으로 다음 요청을 차단한다. 진행 중인 한 요청으로 한도를 넘을 수 있고, 이 경로 외의 사용을 제한하지 않는다. 차단 정책에서 미산정 비용이 있으면 새 요청도 보류한다. 기본 관찰 정책과 일일 100건·월 $20의 초기 설정은 관리자가 수정하는 로컬 설정이며 회사가 승인한 실제 예산이 아니다.

운영 기록과 새 파일은 무시되는 `server/.data/operations/`에만 저장한다. 기존 원본과 정규화 파일은 고정된 감사 메타데이터의 정확한 경로·해시를 대조해 읽는다. 일부 원본은 이전 checkout의 보존 폴더에 있으며 복사·덮어쓰기하지 않는다. 재수집 파일은 격리 보관하고 기존 색인에 자동 반영하지 않는다. 스테이징은 현재 검증된 원문으로 답변/검토 FTS 테이블을 나눠 새 버전을 만들며 기존 벡터를 재생성하지 않는다.

이전 업무 홈은 `/hr/workspace-previous`, 이전 챗봇은 `/hr/assistant-previous`, 기준 시안은 기존 8824에 보존했다. Supabase 적재·SQL·클라우드 배포·PR 생성은 수행하지 않는다.

## 검증

TypeScript 포함 프론트 빌드와 운영 API 검사 24개가 통과했다. API 검사는 실제 고정 원문 목록과 선택 문서의 스테이징 색인 생성, 검색 구간 없는 문서의 빈 재적재 차단, 역할·소유권 분리, 변경 충돌, 토큰·캐시·비용 계산, 단가 시점 보존, 점검/예산 차단, 미확인 비용과 모델 미호출을 구분한다. 합성 공급자 응답을 사용한 검사에서는 실제 모델을 호출하지 않았다.

실제 화면에서 `K-170-A01` 한 문서를 재수집해 247,457바이트와 보존 원문과 같은 SHA-256을 확인했다. 별도 스테이징 작업은 답변 21구간·검토 21구간을 나눈 FTS5 색인을 생성했다. 새 임베딩·현행 검색 색인 변경은 0건이다. 일반 검증 문의 한 건을 접수→관리자 처리 완료→직원의 처리 안내 확인까지 연결했다. 회사 신청이나 외부 메시지는 전송하지 않았다.

실제 질문 「통상근무자의 휴게시간을 업무 사정으로 바꿀 수 있나요?」를 화면에서 전송해 답변과 인용 원문(취업규칙 제20조)을 확인했다. 같은 요청 `REQ-9f4f8b0f846e`의 공급자 호출 3회가 질문 의미 확인→답변 초안→원문 대조로 기록됐다. 입력 9,939·출력 2,245토큰, 캐시 읽기 0·캐시 쓰기 9,930토큰(입력에 포함), 응답 27,797ms, 시점별 단가 추정 $0.002364650이다. 단계별 비용 합계와 요청 합계가 일치하고 요청·답변 본문은 사용량 DB에 저장하지 않는다. 실제 공급자 청구액이나 검색·답변 품질 전체를 검증한 수치가 아니다.

직원 홈·관리자 사용량의 390px 화면에서 페이지 가로 넘침이 없고 모바일 메뉴 전환이 동작했다. 직원 계정 화면은 조건 입력 0개, 활성 복지 링크 0개와 기존 복지 경로의 홈 이동을 확인했다. 14개 화면 구성, 직원/관리자 전환, PC/모바일 와이어프레임과 구현 화면 연결을 확인했다. 원문 검토 메모 저장 후 답변 허용 범위를 유지하고, 변경 이력에서 문의·작업·검토 기록을 확인했다. 회사 SSO·Supabase 보류·검색 버전 활성화·청구서 대조의 연결 경계도 화면에서 확인했다.

화면의 실제 실행 증거와 사용량·문의 흐름의 검사 결과는 `hr-user-admin-20261108/verification.json`에 분리해 기록한다. 기능 연결 검사는 검색 성능 평가·전체 답변의 의미 검증·독립 사람 승인과 다르다.

## 실행

기존 8846 확장 서비스를 유지한 상태에서 `start_hr_portal.cmd`를 실행한다. 이 시작기는 `scripts/launch_hr_operations.py`로 이 checkout의 로컬 8848 운영 서비스가 준비됐는지 확인한 뒤 UI 8825를 시작한다. 다른 서비스가 포트를 점유하면 중지·교체하지 않는다. 운영 서비스는 키나 `.env`를 읽지 않는다.

`npm.cmd run build --prefix web`로 빌드한다. `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1` 환경에서 `python -m pytest operations/test_operations.py -q`로 격리된 운영 검사를 실행한다. 실제 재수집·재적재·문의·모델 호출을 한 화면 확인과 합성 응답 기반 API 검사를 혼합 집계하지 않는다.
