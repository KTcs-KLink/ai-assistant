# 기존 5개 도메인·34개 업무로 분류 범위 정정

사용자 지정 분류는 인사/근태, 총무/행정, 재무/회계, IT/보안, 경영기획/성과관리의 **5개 도메인·34개 업무**다. 이전 작업에서 추가한 도메인·업무는 현재 조회와 분리 파일의 허용 목록에서 제외했다. 이전 확장 결과는 이력으로 보존한다.

## 현재 로컬 결과

원문 파일 단위 203개, 보존 청크 10,205개, 기존 벡터 검색 조각 8,511개를 유지했다. 다른 프로젝트 자료는 추가하지 않았다.

| 도메인 | 기존 업무 직접 자료 | 인접·세부업무 검토 |
|---|---:|---:|
| 인사/근태 | 596 | 200 |
| 총무/행정 | 1,400 | 90 |
| 재무/회계 | 191 | 174 |
| IT/보안 | 237 | 29 |
| 경영기획/성과관리 | 39 | 274 |
| 합계 | 2,463 | 767 |

추가로 5개 도메인 범위 밖 3,625개, 업무 판단 보류 3,339개, 개인정보 패턴 보류 11개를 별도 보관한다. 모두 합쳐 10,205개다. **이 보관 상태는 추가 도메인이 아니다.**

직접 업무 수는 원문 근거가 대조된 기존 자동 분류 제안의 대표 경로 집계다. 독립적인 사람의 의미 승인·현행성·KTcs 적용 승인은 아니다. 일부 직접 자료에도 판단 보류 구간이 함께 남아 있다.

## 정정 방법과 경계

- Codex/코드: 원래 분류표를 읽고 34개 업무 코드·명칭을 정확히 보존했다. 기존 분류의 허용 업무 연결만 남겼다.
- 다른 대표 분류에 있던 청크도 기존 업무의 직접 근거가 있으면 해당 업무로 연결했다. 복수 직접 업무 연결을 유지했고, 관련·참조를 직접 업무로 승격하지 않았다.
- 기존 5개 도메인에 인접하지만 34개 업무와 직접 대응하지 않는 자료는 해당 도메인의 `세부업무검토`에 보관한다. 새 업무 코드를 만들지 않았다.
- 기존 업무 판단 보류는 유지했다. 개인정보 패턴 보류 본문은 표시하거나 새 산출물로 복제하지 않았다.
- GPT: 이번 정정에서는 호출하지 않았다. 기존 원문 근거가 연결된 제안을 재사용했다.
- 원문·정규화 본문·청크 경계·기존 임베딩·골든셋과 이전 결과는 해시로 보존 여부를 검사한다. 재청킹·재임베딩은 하지 않았다.
- 기존 답변 허용 범위 528개 원문 청크·536개 검색 조각을 유지한다. 분류를 검색 성능 평가나 답변 의미 평가로 표현하지 않는다.
- Supabase 적재와 외부 DB 쓰기는 계속 보류한다. PR은 만들지 않는다.

## 파일과 조회

현재 결과는 워크스페이스의 `outputs/klink_five_domain_scope_20261109`에 있다.

- `taxonomy.json`: 정확히 5개 도메인·34개 업무
- `by-domain/<도메인>/<업무>/units.jsonl`: 대표 업무별 원문 청크
- `by-domain/<도메인>/세부업무검토/units.jsonl`: 도메인 인접 자료
- `outside-five-domains`, `review-required`, `privacy-hold`: 별도 보관
- `unit-classification.jsonl`, `window-classification.jsonl`: 원문·벡터 행 ID를 유지한 분류표
- `workflow-memberships.jsonl`: 원래 업무만 허용하는 복수 연결표
- `summary.json`, `artifact-verification.json`: 집계와 실제 원문 보존 검사
- `index.html`: 자료 구분, 5개 도메인, 기존 업무, 문서 검색이 가능한 로컬 조회

`server/.venv/Scripts/python.exe scripts/launch_domain_workflow_view.py --no-open`으로 조회 화면을 시작한다. 기본 주소는 `http://127.0.0.1:8852/`다. 서버는 키를 받지 않는 정적 파일 서버이며, 브라우저에서 모델이나 외부 DB를 호출하지 않는다.

기존 `outputs/klink_domain_workflow_20261109`와 `docs/domain-workflow-classification-20261109.md`는 확장 당시의 이력이다. 현재 분류 기준은 이 문서와 `server/five_domain_scope.py`를 따른다.

## 검증

분류 범위 회귀 검사 7개와 기존 검사 200개, 합계 207개가 로컬에서 통과했다. 전체 원문·청크·벡터 보존 검사는 `scripts/verify_five_domain_scope.py`, 실제 화면 검사는 `scripts/verify_five_domain_browser.js`로 수행한다. 검사 산출물과 브랜치 상태는 로컬 결과 폴더에 별도로 남긴다. 이 검사는 새 답변 평가를 수행하지 않는다.
