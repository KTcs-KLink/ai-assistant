## 주요 흐름

- 업무 현황은 준비 업무 전체·진행 중·재확인 필요와 검색 가능한 조문 수를 기존 API 값으로 표시한다. 조회 실패 시 0건으로 바꾸지 않는다.
- 준비 업무는 상태 필터, 업무명 검색, 이름/진행률 정렬을 제공한다. 항목을 열면 해당 업무의 체크리스트를 직접 수정할 수 있고 API의 재조회 결과로 진행률을 갱신한다. 저장 중에는 조작을 잠그고 저장 상태를 표시한다.
- 재확인이 필요한 업무는 수정할 수 없다. 준비 완료는 실제 신청·승인과 구분한다. 아직 실제 제도로 확인되지 않은 혜택에는 예시 표시를 유지한다.
- 전역 검색은 같은 AI 도우미 화면에서도 새 질문을 작성창으로 전달한다. 질문은 URL에 넣지 않고 이동 상태를 지우며, 사용자가 도우미에서 전송하기 전에는 답변 모델을 호출하지 않는다. 검색 모드 변경 시 긴 질문을 임의로 잘라 넣지 않는다.
- 모바일에서는 메뉴를 대화상자로 열고, 업무 표는 표 영역 안에서 가로로 탐색한다. 업무 데이터가 없는 상태·검색 결과 없음·조회 실패도 구분한다.

기존 홈은 원래 공통 화면을 함께 보존했다: [벤치마킹 홈](http://127.0.0.1:8825/hr/home-benchmark), [초기 연결 홈](http://127.0.0.1:8825/hr/home-previous). 기존 8824 디자인 시안도 유지한다. 원래 체크아웃, 백엔드, 원문·임베딩 색인, 기존 `HrHome.tsx`·`home.css`·`HrPages.tsx`, `portal`·`workspace` 시안은 수정하지 않았다.
