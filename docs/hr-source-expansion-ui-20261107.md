# 확장 원문 범위와 실무형 AI 화면 연결

기준일: 2026-11-07. UI 브랜치: `feat/hr-source-expansion-ui-20261107`. 시작 커밋: `b5c0e4f2a9719a4fef41fc7d29dcbc55b5adab48`.

실제 연결 화면은 `http://127.0.0.1:8825/hr/assistant`다. 기존 8824 시안의 코드·서버와 이전 대화 화면 `/hr/assistant-previous`는 보존했다. 질문·답변, 하단 작성창, 현재 질문 목록, 인용 클릭과 원문 패널, 조건까지 포함한 복사 기능을 유지한다.

위 자료 수와 제외 수는 백엔드 원문 감사 기록 `outputs/klink_hr_source_expansion_20261107/summary-v2.json` 및 실제 readiness 응답을 확인한 값이다. UI 변경에서 전체 원문 감사를 다시 실행하거나 새 임베딩·전체 평가를 수행한 것은 아니다. 검토 발췌에는 인사 외 자료도 있으므로 전체를 승인된 인사 규정으로 표시하지 않는다.

## 실제 변경

- 연결 UI의 로컬 프록시와 시작 전 확인 주소를 8844에서 확장 서비스 8846으로 변경했다. capabilities에서 `source_scope=expanded`를 확인한다. 기존 8844 서비스, 8841 인코더와 원문·벡터는 변경하지 않았다.
- 대화 상단·업무 홈·규정 검색·연결 상태에 답변 참고용 조문과 검토 전용 구간을 나눠 표시한다. 대화 패널에는 답변 근거, 답변용 검색, 검토 발췌 탭이 있다.
- 검토 검색은 `/hr/review-evidence` GET만 사용한다. 검토 경고, 원문 발췌, 한국어 보류 사유와 문자 위치를 표시한다. 검토 결과에는 답변 생성·근거 선택 기능을 붙이지 않는다.
- 검토 검색 응답의 회사·미승인·답변 미사용·발췌 전용 상태를 검사한다. 답변에 검토 전용 자료가 섞이거나 확장 자료의 긍정적인 답변 허용 표시가 없으면 내용을 차단한다. 현재 원문을 다시 열 때도 허용 상태와 본문 SHA를 확인한다.
- `단시간근로자 운영지침`처럼 보류 문서를 지정한 질문은 일반 규정으로 대체하지 않는다. 서버의 `NAMED_SOURCE_HELD_NO_SUBSTITUTE_OR_GENERATION`, 빈 문단·출처·모델 호출 목록을 검사한 뒤 보류와 모델 미호출을 표시한다. 검토 검색 열기는 문서명을 검색창에만 옮기며 질문을 다시 전송하지 않는다. 입력한 `시간제` 등을 고용형태로 새로 추정하는 처리도 추가하지 않았다.

백엔드 의존 브랜치는 `feat/hr-source-expansion-20261107`, 확인한 커밋은 `d1ee080240efb7c8e9fd8c4cdfb06ffe9983efdc`다. 백엔드 브랜치를 UI에 병합하거나 다른 채팅의 작업 파일을 수정하지 않았다. Supabase 확인·적재·SQL과 클라우드 배포는 HOLD다. 키·설정·쿠키는 화면·검증 자료에 복사하지 않는다.

## 검증과 해석 범위

[검증 자료](hr-source-expansion-ui-20261107/verification.json), [실제 답변 PC](hr-source-expansion-ui-20261107/answer-1440.png), [실제 답변 모바일](hr-source-expansion-ui-20261107/answer-390.png), [보류 문서 안내](hr-source-expansion-ui-20261107/held-1440.png), [검토 검색 모바일](hr-source-expansion-ui-20261107/review-390.png)을 보존한다.

- 실제 새 질문 `월급은 매달 며칠 들어오나요?` 1건을 8825 UI에서 8846으로 전송했다. 모델 호출은 질문 이해 1회이며, 지급일은 서버가 원문에서 추출한 답변이다. 생성 초안 1회로 집계하지 않는다. 실제 답변 1문단·인용·현재 원문 열기를 확인했다. 질문만 전송됐고 직원 프로필은 전송되지 않았다.
- 별도 범위 검사 13개에서 실제 capability/readiness, 추가 상임임원 원문 검색·조회, 검토 검색 5건, 실제 보류 문서 질문의 모델 호출 0회, 보류 사유와 검색 이동을 확인했다. 보류 질문은 검사를 반복할 때에도 모델을 호출하지 않는 경로다.
- 과거 실제 응답을 재생한 합성 확장 플래그 검사와 실제 응답 변조 검사를 별도로 표기했다. 검토 전용 자료의 답변 승격, 답변 내 혼입, 허용 표시 누락, 원문 재조회에서 표시 누락, 모순된 모델 미호출 표시가 차단된다. 재생 검사는 새 모델 호출이 아니다.
- 프론트 빌드가 통과했고 1440·768·390·360px에서 가로 넘침이 없었다. 최종 검사에서 브라우저 스크립트 오류, 브라우저 Authorization 헤더, `/api/benefits/config` 조회는 없었다.

이 결과는 화면·전송·출처 연결과 자료 분리 검사다. 검색 성능 평가, 전체 답변의 의미 평가, 독립 사람 승인이나 SaaS 운영 준비 완료를 뜻하지 않는다. 백엔드 채팅이 남긴 상임임원 답변·3회 모델 호출 및 165개 테스트 기록은 이 UI 작업의 신규 실행 수에 합산하지 않는다. Codex는 화면과 검사를, 앱 코드는 검색·출처·상태 검사를, 지정 GPT는 실제 요청에서 질문 이해를 수행했다.

## 재현

`npm.cmd run build --prefix web`로 빌드하고 `python scripts/check_hr_closeout_service.py`로 지정 서비스를 확인한다. `start_hr_portal.cmd`는 확인을 통과한 서비스에만 연결한다.

보존 응답이 있는 로컬 환경에서 `python scripts/prepare_hr_expanded_scope_ui.py` 실행 후 Playwright CLI로 `output/playwright/verify_hr_expanded_scope_ui.generated.js`를 실행한다. 일반 답변 POST는 가로채고, 보류 문서 질문 1건만 실제 서비스로 전달해 모델 미호출을 검사한다. `scripts/verify_hr_expanded_answer_live.js`는 실제 새 질문과 모델 호출을 발생시키므로 재생 검사와 구분한다. 전체 원문 응답·재생 파일·브라우저 임시 자료는 무시되는 `output/playwright`에만 보관한다.
