## 발견한 문제와 변경

1. 보직·재고용·휴게·결근·건강진단 등 정상 인사 질문이 범위 검사에서 차단됐다. 인사 어휘와 원문 표제어 대응을 보완하고 일반 질문 표현의 영향은 줄였다. 평가 질문·정답·골드 ID는 검색 색인에 넣지 않았다.
2. 줄바꿈·항 사이 개정일 주석·조 제목의 적용대상 숫자·원 안 숫자 항 번호 때문에 올바른 답변이 가려졌다. 유일하게 연결되는 실제 원문 범위를 복원한다. 반환 인용은 항상 원문에 연속해서 존재한다. 문구·수치 변경이나 모호한 위치는 허용하지 않는다.
3. 같은 조의 선행 항을 참조하는 경우 원문 항을 포함해 수치 근거를 보존한다. 다른 조·법률의 참조를 같은 조 항으로 자동 해석하지 않는다. 모든 조문 의존관계가 해결됐다는 뜻은 아니다.
4. 육아휴직의 의무발령/불이익 금지, 학자금 해외 한도/환율, 결근 사전승인 원칙 등 누락을 확인했다. 같은 지정 모델의 원문 재검토 단계를 추가했다. **동일 모델 재검토는 독립 검증이 아니다.**
5. 교육 낙제의 원문 `출석 및 성적`을 답변이 `출석 또는 성적`으로 완화한 오류를 Codex가 확인했다. 자동 의미 채점은 이를 통과시켰다. 해당 답변을 새로 생성해 연결 표현 보존을 재확인했고, 조건 술어의 연결 완화를 보류하는 검사를 추가했다. 학교 종류처럼 대상을 열거하는 `및`은 두 학교 동시 재학 조건으로 오해하지 않도록 구분했다. 이 검사가 모든 논리 오류를 검출하지는 않는다.
6. 근거 없는 안내 문단 하나 때문에 확인된 업무 설명 전체가 사라졌다. 검증되지 않은 문단은 표시하지 않고 확인된 문단만 남기며 `needs_review`를 강제한다. 필수 미확인 항목을 잘라 통과시키지 않는다.
7. 모델 본문과 별도로 **인용한 원문 항 전체**를 `source_conditions`로 화면에 바로 표시한다. 앞의 원칙과 뒤의 예외를 잘라내지 않는다. 이는 인용한 항의 보존이며 모든 필수 조문 검색·회사 적용·사람 승인을 보증하지 않는다.
